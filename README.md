## Current project
### [Micro quadcopter with a custom flight controller](https://github.com/nicholassiu1/arduino-micro-quadcopter)
A sub-100 g quadcopter built from scratch. I'm designing the frame in SolidWorks, printing it in PETG, and writing the flight control code (sensor filtering, cascaded PID, motor mixing, failsafes) myself for an Arduino Nano. The handheld radio transmitter is also my own build.
Target: a stable indoor hover by January 2027. Progress is tracked in the repo's milestones.

**Tools:** C++ (Arduino) · SolidWorks · 3D printing · soldering and circuit design · Git/GitHub
